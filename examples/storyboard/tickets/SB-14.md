# SB-14 Filter stories by assignee

As a team member I want to list only the stories assigned to one person.

1. `GET /api/stories?assignee=Ana` returns only Ana's stories.
2. The filter ignores case, so `ana` works too.
3. A name with no stories returns an empty list, status 200.
4. `assignee` can be combined with `status`, and both must match.
